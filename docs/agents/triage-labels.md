# Triage labels

| Fachrolle | GitHub-Label | Bedeutung |
| --- | --- | --- |
| needs-triage | needs-triage | Muss fachlich bewertet werden. |
| needs-info | needs-info | Wartet auf Rueckmeldung oder fehlende Informationen. |
| ready-for-agent | ready-for-agent | Voll spezifiziert und durch einen Agenten umsetzbar. |
| ready-for-human | ready-for-human | Erfordert eine menschliche Umsetzung oder Entscheidung. |
| wontfix | wontfix | Wird nicht umgesetzt. |
