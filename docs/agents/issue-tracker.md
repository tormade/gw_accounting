# Issue tracker: GitHub

PRDs und Umsetzungsaufgaben werden als GitHub Issues im Repository `tormade/gw_accounting` verwaltet.

## Konventionen

- Issues erstellen, lesen, kommentieren und labeln erfolgt mit der `gh`-CLI im Repository.
- Wenn ein Skill ein Ticket veroeffentlicht, erstellt er ein GitHub Issue.
- Externe Pull Requests sind keine Triage-Quelle.
- Neue, voll spezifizierte Umsetzungsaufgaben erhalten das Label `ready-for-agent`.
