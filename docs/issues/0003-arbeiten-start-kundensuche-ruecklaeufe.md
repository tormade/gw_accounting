## What to build

Create the first screen of `Arbeiten` as a real daily workplace with two clear tasks: customer search/order intake and open delivery-note returns. The screen should be understandable without knowing the old module structure.

## Acceptance criteria

- [ ] `Arbeiten` opens to a start state with customer search/order intake and open returns.
- [ ] The customer search path is immediately visible.
- [ ] Open delivery-note returns are visible as a separate task area.
- [ ] The layout supports desktop side-by-side presentation and remains readable at smaller widths.
- [ ] Empty states explain what to do when there are no customers or no open returns.
- [ ] UI tests cover both task areas.
